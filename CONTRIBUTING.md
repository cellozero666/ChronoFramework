# Contributing to CHRONO

CHRONO is currently specification-first and preparing its initial implementation. Contributions must preserve the authority order and invariants in the [documentation index](docs/README.md).

Before submitting a change:

1. read [AGENTS.md](AGENTS.md) and the normative documents it lists;
2. keep changes scoped and traceable to an approved requirement or documented issue;
3. include tests and security evidence appropriate to the affected boundary;
4. update documentation in the same change when behavior or contracts change;
5. do not weaken approval, security, RTK, process-skill, verification, or correction gates.

Do not include secrets, credentials, private project data, generated caches, build output, or machine-specific configuration. Unless explicitly marked otherwise, intentionally submitted contributions are accepted under the repository's [Apache License 2.0](LICENSE), consistent with Section 5 of that license.
