# Security Policy

CHRONO is not yet released. Security findings should not be disclosed in a public issue.

Use GitHub's private vulnerability reporting for the [ChronoFramework repository](https://github.com/cellozero666/ChronoFramework/security/advisories/new) when available. If that channel is unavailable, wait for the repository owner to publish an authorized private contact method; do not place exploit details, secrets, or sensitive evidence in public discussions.

All implementation changes must follow the security roles, two mandatory Product Owner security decisions, signed approval rules, least-privilege requirements, and fail-closed gates defined in the normative documentation.
